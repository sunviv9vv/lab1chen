# Lab 1 — Intro to Behavioral TV Data

**Name:** Chen Xinwei  
**Group:** KM-42

This repository contains `lab1.ipynb` for the Fundamentals of Ad Tech, Data & Analytics course. It analyzes October 2024 synthetic TV panel data, including ratings, reach, frequency, and network audiences by age and gender.

The notebook includes saved numerical outputs and plots. To run it, open it in Google Colab or Kaggle and select **Run all**. The setup cell downloads version 2 of the course dataset with `kagglehub`; the data files are not stored in this repository.
